# Spendwise – Expense Tracker

A simple web app to track income and expenses.

## Features
- Add income and expense transactions
- Live balance, income and expense totals
- Spending by category chart
- Search and filter by category or month
- Export to CSV
- Data saved in the browser (localStorage)
- Responsive, with dark mode support

## Tech
HTML, CSS, JavaScript (no frameworks)
